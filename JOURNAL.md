# September 12th: Day 1

Started to design and plan the hardware that I would use. The idea of this project came to me when playing a flight sim on my phone and thinking 
"How small can I make a flight sim?". I decided to use an inventr.io HERO board for this project because I had it just lying around. It is almost identical to an Arduino UNO.
This was my first time wiring something like this so it took a while. I originally was just gonna use a joystick but realized that I needed a throttle so I added a potentoimeter.
<img width="1152" height="1536" alt="51B667EC-1691-47B3-93B2-701348A0F685" src="https://github.com/user-attachments/assets/01c0eddd-59c5-455f-8f10-a1dc903bdf4d" />
Materials I used: Inventr.io board, 1.3 inch OLED Screen, 2 axis joystick, 10k potentiometer, Breadboard, and 14 wires.

**Total time spent: 4h**
# September 13th: Day 2

I tried to test the hardware but for some reason the screen was not working or turning on. I was very frustrated for an hour as a double checked my wiring, and code. Everything seemed right.
