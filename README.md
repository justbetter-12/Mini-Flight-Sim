# Mini-Flight-Sim
Mini flight sim controlled by a joystick and a potentiometer. It uses an Arduino UNO. Sorry if my journal entries are not super great. I'm not great at documenting my work but am trying to get better.

**Wiring**

**Joystick → Arduino Uno**

GND → GND

5V → 5V

VRX → A1 

VRY → A0

SW → D2 

**OLED display → Arduino Uno**

GND → GND

VCC → 3.3V

SCK → SCL

SDA → SDA

**Potentiometer (throttle) → Arduino Uno**

Left pin → GND

Middle pin → A2

Right pin → 5V
